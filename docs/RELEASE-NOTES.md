## v4.12.4

**AI 助理更好用了**

- 便签卡片与详情弹窗现在都显示 #id，AI 对话里的便签卡片同样标注——AI 修改/删除便签时自己查 id，不再反问你要编号
- 修复 AI 对话中便签卡片时间显示 NaN-NaN-NaN 的乱码问题
- AI 创建便签的 id 链路加固：落库后反查完整记录，杜绝 id=0 异常
- 对话消息右下角的"⚡共N块"调试标记替换为 token 用量：显示 ↑输入 ↓输出 token（渠道不支持时按字数估算，带 ≈ 前缀）

## v4.12.3

**修复快捷面板滚动**

- 快捷面板内容超出后无法滚动的问题彻底修复：布局改用固定锚定（fixed inset:0），不再依赖 WebView 高度链解析，搜索/AI 对话页面内容再多也能滚到底
